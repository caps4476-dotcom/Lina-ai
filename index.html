🔑 OpenRouter API-Key eingeben

Du brauchst einen kostenlosen Key von OpenRouter.

So geht es (2 Minuten):
1. Geh auf openrouter.ai
2. Tippe oben rechts auf "Sign In"
3. Mit Google Konto einloggen
4. Tippe oben rechts auf dein Profilbild
5. Tippe auf "Keys"
6. Tippe auf "Create Key"
7. Den Key hier unten einfuegen
